# Mídias do demo Freios & Elétrica Modelo XGR

Este site foi estruturado para funcionar com placeholders visuais enquanto as imagens e o vídeo ainda não existem. Quando os arquivos forem criados e enviados com os nomes abaixo, o JavaScript tenta carregá-los automaticamente nos blocos corretos.

## Vídeo do hero

- `assets/video/hero-oficina-freios-eletrica.mp4`
  - Cena sugerida: oficina automotiva moderna, mecânico trabalhando em freio ou diagnóstico, iluminação escura, contraste forte, movimento lento e profissional.
- `assets/img/hero-poster-freios-eletrica.jpg`
  - Poster do vídeo. Use como fallback visual quando o vídeo não carregar.

- Paleta: preto, grafite, branco gelo, laranja automotivo.

- Evitar: imagem genérica com cara de banco de imagem barato, sorriso falso, oficina bagunçada, texto dentro da imagem e estética de panfleto.
